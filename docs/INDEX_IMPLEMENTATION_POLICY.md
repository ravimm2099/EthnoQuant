# Formula registry and implementation policy

**Registry size:** 69 source records. **Operational coverage:** consult the About tab inventory, which lists actual calculation families and analysis windows. Counts of registry entries classified “ready for testing” do not equal the number of tested executable calculators.

**Under development:** All catalog entries without an explicit source-to-function mapping and a passing numerical test remain reference-only. Some require binary presence/absence matrices; others need original scoring protocols, informant-level event data, policy flags or verified source equations. A missing source equation is not inferred.

The complete abbreviation, formula text and verification status for each record is preserved in `reference/formula_catalog.csv`, displayed in the About tab and downloadable as `EthnoQuant_registry_development.csv`.

**Important:** The Campos–Albuquerque CPI calculator is a separately sourced formulation; it must not automatically be counted as the same method as registry #59 or #63.
