# GitHub and Zenodo release preparation

This ZIP is a **publication-preparation package**, not evidence that any repository or Zenodo DOI has been created.

1. Run and test the complete Shiny app in RStudio, including example inputs and numerical benchmarks.
2. Inspect and choose an explicit open-source license; replace any license-selection placeholder.
3. Check `CITATION.cff`, README, authorship, affiliation, citation metadata and version for accuracy.
4. Create a GitHub repository named `EthnoQuant`; upload the entire contents of the `EthnoQuant/` folder (not the ZIP as a single file). Do not upload confidential survey data.
5. Create a tagged release after tests pass; retain release notes and test results.
6. Connect the GitHub repository to Zenodo, enable archiving, then publish the GitHub release to mint the archival DOI.
7. Insert the real GitHub URL, release tag, license and Zenodo DOI into the software paper only after publication.

No repository URL or DOI is invented here.
