# Data types and example files

The **Data types & templates** tab provides a searchable analysis-specific input guide, exact column names, the first six rows of each supplied CSV, and one-click example downloads. A full machine-readable data dictionary is in `data/ANALYSIS_DATA_DICTIONARY.csv`.

For Venn diagrams, supply `set,item` membership data with 2–5 unique set names. `ggVennDiagram` and `ggplot2` are optional dependencies for the overlapping Venn display; exact counts remain in the results table. Install with `install.packages(c("ggVennDiagram", "ggplot2"))`. Overlap areas are not guaranteed proportional to set sizes.

These example CSVs are demonstrations, not scientific validation datasets.
